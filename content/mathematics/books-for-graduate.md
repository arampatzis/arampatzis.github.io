Here, you will find books to refresh your knowledge of basic mathematics and programming.


# Mathematics

## Basics

- [Mathematics for Machine Learning](https://mml-book.github.io): 
This book can be used to refresh your memory on undergraduate mathematics, 
which is useful in many fields, especially in ML. 
The authors provide the [pdf](https://mml-book.github.io/book/mml-book.pdf) for free.


# Machine Learning

## Introduction

- [Pattern Recognition and Machine Learning](https://link.springer.com/book/9780387310732):
The best book to expose yourself on classical machine learning algorithms.
Can be found for free [here](https://www.microsoft.com/en-us/research/uploads/prod/2006/01/Bishop-Pattern-Recognition-and-Machine-Learning-2006.pdf)

## Deep Learning

- [Deep Learning: Foundations and Concepts](https://www.bishopbook.com):
Learn the most important neural network architectures.
The authors provide 
[solutions](https://www.bishopbook.com/Concepts_in_Deep_Learning_Solutions_v1.0.pdf) 
to the exercises.


# Programming

## Python

- [Python Crash Course](https://nostarch.com/python-crash-course-3rd-edition): 
If you don't know Python, start with this book.

- [Fluent Python](https://www.oreilly.com/library/view/fluent-python-2nd/9781492056348/):
If you want to become an expert in Python, read this book. At least the first half in order
to call yourself an expert at the basics of Python.

## Pythorch

- [Programming PyTorch for Deep Learning](https://www.oreilly.com/library/view/programming-pytorch-for/9781492045342/):
Learn Pytorch on modern applications. The book can be found for free 
[here](https://ia601308.us.archive.org/29/items/book1_202402/programming-pytorch-for-deep-learning-creating-and-deploying-deep-learning-applications.pdf)
